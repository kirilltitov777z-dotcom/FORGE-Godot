# FORGE — Godot 4

Минималистичная игра с кейсами, апгрейдом и инвентарём. Проект на **Godot 4.3 + GDScript**, без внешних зависимостей и без HTML. Монеты виртуальные, рисуются в интерфейсе и обозначаются ₽.

## Где взять APK

GitHub Actions собирает APK при каждом push в `main` и публикует его в Release:

- Скачать: https://github.com/kirilltitov777z-dotcom/FORGE-Godot/releases
- Лог сборки: https://github.com/kirilltitov777z-dotcom/FORGE-Godot/actions

APK также доступен артефактом `FORGE-APK` в каждой успешной сборке. Ключ подписи создаётся прямо в workflow, поэтому в репозитории нет секретов.

## Что внутри

- **305 скинов**: 120 обычных, 80 редких, 60 эпических, 35 легендарных, 10 уникальных. Графика рисуется кодом (`scripts/DrawUtil.gd`) из силуэтов 10 типов предметов — картинки не нужны.
- **Интерфейс в стиле референса**: тёмно-синий фон с золотым акцентом, круглый барабан апгрейда с метками 0/50/100%, нижняя навигация, ставки x2/x4/x8 и шансы 25/35/55/75%.
- **Приятные звуки**: мягкие синтезированные перезвоны для кликов, открытия кейса, победы, потери, продажи и бонуса. Файлы генерируются скриптом `tools/generate_sounds.mjs`, отключаются кнопкой ♪.
- **36 кейсов** с разными ценами, темами и таблицами шансов. Шансы показываются перед открытием.
- **Апгрейд** с пресетами **25% / 55% / 75%** и своим шансом 5–95%. Предмет и цель выбираются вручную, доплата считается с учётом 12% комиссии.
- **Инвентарь**: фильтры, сортировка, выделение нескольких предметов и продажа пачкой за 65%.
- **Свои кейсы**: название, цена, описание, набор скинов и свои шансы. Создание стоит **1 500 ₽**, редактирование бесплатно.
- **Экономика**: 3 000 ₽ старта, +500 ₽ раз в сутки, честное распределение редкостей.
- **База данных**: в разделе «Мастерская» можно вставить JSON со скинами/кейсами или полный бэкап, а также скачать бэкап в `user://forge_backup.json`.
- Сохранение — `user://forge_save.json`.

## Структура

```
project.godot                 настройки проекта
main.tscn                     главная сцена
icon.svg                      иконка приложения
export_presets.cfg            пресет Android для GitHub Actions
scripts/Main.gd               экономика, экраны, анимации, сохранения
scripts/DrawUtil.gd           HSL→Color, силуэты оружия, куб кейса, монета
scripts/SkinCard.gd           карточка скина
scripts/CaseCard.gd           карточка кейса
scripts/SkinArt.gd            отрисовка скина
scripts/CoinIcon.gd           монета ₽
data/skins.json               305 скинов
data/cases.json               36 кейсов
data/config.json              параметры экономики
tools/generate_data.mjs       генератор данных
tools/generate_sounds.mjs     генератор звуков
audio/*.wav                   звуки интерфейса
scripts/Wheel.gd              круглый барабан апгрейда
.github/workflows/build-apk.yml  сборка и публикация APK
```

## Формат базы данных

```json
{
  "skins": [
    {
      "id": "s0001",
      "name": "Винтовка «Графит»",
      "weapon": "rifle",
      "rarity": "common",
      "value": 95,
      "hue": 210,
      "sat": 14,
      "light": 42
    }
  ],
  "cases": [
    {
      "id": "c01",
      "name": "Старт",
      "price": 150,
      "hue": 210,
      "weights": { "common": 70, "rare": 22, "epic": 6.5, "legendary": 1.4, "unique": 0.1 },
      "pool": ["s0001"],
      "desc": "Описание"
    }
  ]
}
```

`hue/sat/light` задают цвет в HSL. Типы оружия: `rifle`, `pistol`, `sniper`, `smg`, `shotgun`, `knife`, `carbine`, `revolver`, `axe`, `bat`. Редкости: `common`, `rare`, `epic`, `legendary`, `unique`.

## Локальный запуск

Откройте папку проектом в Godot 4.3 и нажмите F5. Для экспорта вручную: Project → Export → Android (нужны Android SDK и JDK 17).
